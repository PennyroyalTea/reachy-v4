# reachy-v4

An expressive voice deserves an expressive body.

This is an agent skill that makes a [Reachy Mini](https://www.pollen-robotics.com/reachy-mini/) robot act out speech from ElevenLabs Eleven v4. Eleven v4 takes emotion tags such as `[curious]`, `[laughs]` or `[whispers]` in the text. The skill reads the same tags and turns them into body language, so the voice and the robot's head, antennas and body change together.

Ask your agent for something like "make my robot tell me it lost its charger". It writes a tagged script, generates the speech and performs it on your robot.

## What you need

- a Reachy Mini on the same network as your computer. It is tested on Reachy Mini Wireless with robot software 1.10, and in the simulator with 1.11. No robot yet? The skill can run a 3D simulator instead.
- [uv](https://docs.astral.sh/uv/)
- an agent that supports skills, such as Claude Code
- for your own scripts, either the ElevenLabs MCP server connected to your agent, or an ElevenLabs API key. The demo scene needs neither.

## Install

In Claude Code:

```text
/plugin marketplace add pennyroyaltea/reachy-v4
/plugin install reachy-v4@reachy-v4
```

For other agents, or to install it by hand, copy the `skills/reachy-v4` folder to where your agent loads skills from. For Claude Code without plugins, that is `~/.claude/skills/reachy-v4`.

## Try it

Ask your agent:

- "Play the Reachy v4 demo." This plays the cake scene from the demo video, with its audio included.
- "Make my robot tell me it lost its charger."
- "I made this in the ElevenLabs app, make the robot act it out." Then give it the file and the tagged text.
- "Add a proud emotion to my robot."

You can also use the command line tool directly:

```bash
cd skills/reachy-v4
uv run --project engine reachy-v4 check
uv run --project engine reachy-v4 demo
uv run --project engine reachy-v4 say "[curious] Hmm. What's in the box? [gasps] Oh wow, it's for me!"
```

`say` needs `ELEVENLABS_API_KEY` in your environment.

## How it works

1. Each tag maps to one of 10 emotions: happy, excited, laughs, sad, sighs, angry, gasps, scared, curious and whispers. Words such as "slightly" or "very" inside a tag change the strength.
2. Word timings from Eleven v4 place each emotion on the word where the feeling changes.
3. Each emotion opens with a gesture from Pollen Robotics' emotion library, then holds a pose with small idle motion. The head also sways with the loudness of the voice and adds an accent on stressed syllables, in the style of the emotion.
4. Every frame is checked against the robot's real 3D shapes and its reach, so the head keeps at least 10 mm away from the body.
5. The motion and the audio are uploaded to the robot together and play on the robot's own clock, so Wi-Fi delays cannot put them out of sync.

You can add your own emotions as JSON. See `skills/reachy-v4/references/custom-emotions.md`.
